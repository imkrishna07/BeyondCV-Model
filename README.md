# BeyondCV Model

> AI-powered candidate evaluation and job-specific ranking system.

BeyondCV analyzes a candidate's **resume, projects, GitHub, LeetCode, Codeforces, Kaggle, research, certifications, and achievements** to determine how well their skills and experience match a specific job.

## How It Works

```text
Candidate Data
      ↓
Individual Analyzers
      ↓
Feature Aggregator
      ↓
Job Description Analyzer
      ↓
Job-Specific Ranking
      ↓
Explainable Candidate Score
